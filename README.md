# 霜语：遗迹之下

使用 HTML、CSS、JavaScript 与 Canvas 制作的二维横向动作游戏，包含五个场景、剧情交互、Boss 战、王冠终式、通关纪念、存档和死亡重试。团队通过策划、生成方案选择、素材适配及程序整合完成游戏；角色图像、动画、部分配音和代码包含 AI 辅助。

## 运行

完整克隆或下载仓库并保留目录结构，使用桌面版 Edge 或 Chrome 打开 [开始游戏.html](开始游戏.html)，也可直接打开 [index.html](index.html)。浏览器有本地访问限制时，可通过静态 HTTP 服务运行。

声音需点击或按键解锁，可在游戏内调节。存档保存在当前浏览器本地，更换浏览器、目录或清理数据可能影响旧存档。

## 基本操作

A/D 移动，空格跳跃，J 远程攻击，K 近战与蓄力附魔，S 防御，E 闪避；F 交互，W 传送，H 查看完整操作说明。死亡动画结束后可重新开始本关。

## 制作与说明

成员 B 负责场景设计，成员 A 负责其余策划、AI 工具操作、素材与程序整合、声音接入及测试。ComfyUI 用于角色图像等生成与处理工作流，相关素材还涉及 Qwen Image、imagegen、百炼万相及 Qwen3-TTS；程序与处理脚本包含 Codex 等工具的辅助。
